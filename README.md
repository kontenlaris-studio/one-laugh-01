One line, one laugh: the microwave announces the food is done with a
cheerful beep, yet never once apologizes for the three minutes
I stood there waiting on it.

## Run it

```sh
python3 main.py
```

The entry line (102 characters) is written to `/output/entry.txt`.
Running it twice produces byte-identical output — the program is
fully deterministic and uses only the Python standard library.

## How to run

No dependencies to install: any Python 3 will do. From this folder,
`python3 main.py` is the whole setup; check the result with
`cat /output/entry.txt`.
